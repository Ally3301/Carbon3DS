# Extration Status 

Currently, the extraction status is as follows:

**A blend of the PSP and Zeebo versions.**

A lot of data wasn't extracted from the Zeebo because it was an unpopular console and lacked good tools, so I had to create most of it myself.
So, to resolve this, I decided to study both versions of the game simultaneously; they share many similarities, and this allows the runtime to use both at the same time.

*Unfortunately, although the Zeebo extraction is further along, the PSP version still suffers from inconsistent textures; 
I managed to grab a few manually, but there is no automated way to migrate the entire project to the PSP data.*
